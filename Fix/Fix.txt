STEP 2: เพิ่มสถานะกิจกรรม
เพิ่ม Setting:
EventStatus = OPEN | POST_EVENT | CLOSED

ความหมาย:
OPEN = เปิดกิจกรรม แสดง Onsite/Online และรับแจ้งโอน
POST_EVENT = จบกิจกรรม แต่ยังรับบริจาค ซ่อน Onsite/Online
CLOSED = ปิดรับบริจาคและปิดแบบฟอร์ม

ถ้าไม่มีค่าเดิมให้ Default = OPEN

เพิ่มตัวเลือกในหน้า Settings:
- เปิดกิจกรรม
- สิ้นสุดกิจกรรม แต่ยังรับบริจาค
- ปิดรับบริจาค

เพิ่ม Optional Setting:
AutoUpdateEventStatus = true | false

ถ้าเปิด Auto:
- ก่อนหรือเท่ากับ EndDate ใช้ OPEN
- หลัง EndDate ใช้ POST_EVENT
- ถ้า Admin เลือก CLOSED ให้คง CLOSED
- วันสิ้นสุดให้นับถึง 23:59:59 ตาม Timezone ระบบ

STEP 3: หน้า Public
OPEN:
- แสดงปุ่ม “บริจาคเลย” ตามเดิม

POST_EVENT:
- แสดงปุ่ม “บริจาคเพิ่มเติม”
- แสดง Banner:
  “กิจกรรมสิ้นสุดแล้ว แต่ยังเปิดรับการสนับสนุนเพิ่มเติม”

CLOSED:
- ซ่อนปุ่มบริจาค
- แสดง “ขณะนี้โครงการปิดรับการสนับสนุนแล้ว”
- ห้ามเข้า Form ผ่าน URL โดยตรง

STEP 4: Donation Form
OPEN:
- แสดง Onsite / Online
- AttendanceType Required ตามเดิม
- Backend กำหนด DonationPhase = EVENT_PERIOD

POST_EVENT:
- ซ่อน Onsite / Online
- ยกเลิก required และล้างค่าที่ค้าง
- Backend กำหนด AttendanceType = PostEvent
- แสดง Radio “ลักษณะการสนับสนุน *”
  NEW = บริจาคครั้งแรก
  ADDITIONAL = สนับสนุนเพิ่มเติมจากยอดเดิม
- เมื่อเลือก ADDITIONAL ให้แสดงช่อง Optional:
  PreviousDonationReference
  Placeholder: ชื่อ เบอร์โทร หรือเลขที่รายการเดิม
- เมื่อเปลี่ยนกลับ NEW ให้ซ่อนและล้างค่า
- Backend กำหนด DonationPhase = POST_EVENT

CLOSED:
- ไม่ Render Form และห้าม Submit

STEP 5: Backend Validation
- อ่าน EffectiveEventStatus ล่าสุดทุกครั้ง
- ห้ามเชื่อ EventStatus, AttendanceType หรือ DonationPhase จาก Client
- CLOSED ให้ Reject ก่อน Upload/Write
- OPEN รับ AttendanceType เฉพาะ Onsite/Online
- POST_EVENT บังคับ AttendanceType = PostEvent
- ContributionType อนุญาตเฉพาะ NEW/ADDITIONAL
- ถ้า NEW ให้ PreviousDonationReference = ""
- จำกัด Reference ไม่เกิน 200 ตัวอักษร

STEP 6: Google Sheets
เพิ่ม Header ต่อท้าย Donations:
- ContributionType
- PreviousDonationReference
- DonationPhase

ต้องตรวจ Header ก่อนเพิ่ม ป้องกันซ้ำ และใช้ LockService เฉพาะช่วงเขียน

Fallback ข้อมูลเก่า:
- ContributionType = NEW
- PreviousDonationReference = ""
- Onsite/Online ให้ DonationPhase = EVENT_PERIOD
- PostEvent ให้ DonationPhase = POST_EVENT
- ห้ามอัปเดตข้อมูลเก่าทั้ง Sheet อัตโนมัติ
